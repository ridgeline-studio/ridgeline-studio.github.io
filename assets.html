Procedural Nature Kit v1.0

Eight reusable forest assets for environment artists. Clean Blender project, individual OBJ/MTL files, a README and reference renders.

What's inside

Ancient Tree Fern Clump Grass Clump Rock Cluster Fallen Log Fungi Cluster Stream Tile Forest Floor Patch

Every asset is metrically scaled, based at z = 0, organised into a named collection and exported as Y-up OBJ/MTL with UVs. Bark grain runs along the tube axis; grass has no floating seed heads.
