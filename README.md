# Ridgeline Studio website

Static source for <https://ridgeline-studio.github.io>.

- `index.html` — single-page portfolio and free-asset landing page.
- `styles.css` — responsive dark-theme styling.
- `pfp.png`, `hero.png`, `forest.png`, `kit.png` — metadata-stripped PNGs.

No build step, frameworks, or external assets. The page is served directly by GitHub Pages from the `main` branch.
